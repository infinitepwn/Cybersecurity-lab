\section{实验三：使用 Scapy 构造 ICMP Echo Request}
\subsection{实验目的}
\begin{enumerate}
\item 学习和掌握Scapy工具的功能和使用方法，掌握Scapy构造包的流程;
\item 掌握ICMP包的结构，了解一个完整的ICMP包都需要满足哪些条件；
\item 实践网络数据包的伪造与发送，使用Scapy向受害者发送伪造的ICMP数据包。
\end{enumerate}

\subsubsection{创建ip层}
将源ip（src）设置为User ip，将目的ip（dst）设置成Victim ip；
\begin{lstlisting}[language=bash]
ip_layer = IP(src="192.168.4.105", dst="192.168.3.10") 
\end{lstlisting}
通过ls(ICMP)查看ICMP层默认字段值，其中type=8 和 code=0 组合起来表示 ICMP Echo Request（Ping） 数据包，未设置的字段将使用其默认值填充;
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/exp3_icmp.png}
    \caption{创建ip层、查看ICMP层}
    \label{fig:exp3_icmp}
\end{figure}
\subsubsection{创建icmp层、payload}
\begin{lstlisting}[language=bash]
icmp_layer = ICMP() #创建ICMP层
\end{lstlisting}
创建负载数据；
\begin{lstlisting}[language=bash]
payload = "I come from Attacker-192.168.2.100"#载荷的内容
\end{lstlisting}
\subsubsection{构造ICMP Echo Request数据包}
将IP层、ICMP层、负载层三者进行组合，生成一个Ping数据包；
\begin{lstlisting}[language=bash]
icmp_request = ip_layer / icmp_layer / payload
\end{lstlisting}
通过.show()方法来查看已构造好的数据包内容；

但是为什么这里是192.168.3.254?这是因为Docker的网络默认会打开ip masquerade,也就是ip伪装,网关会将源IP地址替换为自身的地址\cite{docker-bridge}

有趣的是，这正是我们这个实验要做的事，不就是伪装吗？
我们需要在docker-compose.yaml里修改一下这个参数(附录里是修改完的)
